# Blinder

## Auteur

Ce projet a été conçu et développé sous le pseudonyme **yanis_cag**.

## Description

**Blinder** est une application web de blind test. C'est-à-dire qu'à partir d'une playlist publique Deezer (votre compte peut être privé mais pas la playlist), vous devez deviner le titre de la musique qui est en cours de lecture. Pour lancer une partie, il faut indiquer l'identifiant de votre playlist, qui est situé à la fin de l'URL : `https://deezer.com/playlist/IDENTIFIANT`.

## Stack technique

- **Frontend :** HTML5, CSS3, JavaScript natif
- **API :** API publique Deezer
- **Qualité de code :** Prettier (formatage automatique)
